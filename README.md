# E-Meal Kitchen: booking system with table buttons, table bills and a kitchen screen

### Main problem 

Papper till kök tar tid och energi.
Varor eller produkter som är slut måste vi veta om i realtid INNAN kunden bestämmer sig så det inte blir en besvikelse.

### Main function

1. The waiter takes an order on the phone: choose a table, tap dishes, add a note.
2. It appears on the kitchen screen right away.
3. The kitchen marks it done, and the waiter can see it.
